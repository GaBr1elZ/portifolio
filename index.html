Sobre Mim

Desenvolvedor Full-Stack com foco em React, com experiência na construção e manutenção de interfaces web para sistemas empresariais. Atuo no desenvolvimento de dashboards, fluxos de interface e funcionalidades integradas a APIs REST utilizando JavaScript (ES6+), HTML e CSS. Atualmente contribuo para a modernização de uma plataforma de atendimento omnichannel, participando da migração gradual da interface construída em jQuery e Bootstrap para uma arquitetura baseada em React e componentização.
