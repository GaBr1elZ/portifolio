# Portfólio Profissional - Gabriel Machado Calegari

Um portfólio pessoal moderno, altamente responsivo e desenvolvido com a estética de **Glassmorphism**. Este projeto foi criado para apresentar minha trajetória como Desenvolvedor Full Stack, destacando minhas habilidades técnicas, links de contato e estudos de caso aprofundados dos meus principais projetos.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias puras da web para garantir máxima performance, carregamento rápido e total controle sobre o design:

- **HTML5** (Semântico e acessível)
- **CSS3 Vanilla** (Variáveis CSS, Flexbox, CSS Grid, Animações customizadas, Responsividade)
- **JavaScript Vanilla** (Interação da interface, animações de scroll com IntersectionObserver, efeito máquina de escrever, lógica de menu mobile)
- **GLightbox** (Biblioteca leve para visualização das galerias de imagens em tela cheia)
- **FontAwesome** (Ícones SVG otimizados)

## 📂 Estrutura do Projeto

O portfólio é composto por uma página principal e páginas secundárias focadas em documentar a arquitetura e os desafios de cada projeto:

- `index.html`: Página inicial contendo a apresentação (Hero), seção "Sobre", "Habilidades Técnicas", "Projetos em Destaque" e "Contato".
- `projeto-cloudchat.html`: Estudo de caso detalhado do **CloudChat**, uma plataforma SaaS de atendimento ao cliente em tempo real construída com React, Node.js, Redis, Socket.IO e Prisma.
- `projeto-tcc.html`: Estudo de caso detalhado do aplicativo mobile de Enoturismo, desenvolvido com React Native, Node.js, TypeScript e MySQL.
- `css/style.css`: Arquivo centralizado contendo o design system, animações e responsividade.
- `js/script.js`: Arquivo para manipulação do DOM e animações.

## 💻 Como Executar o Projeto Localmente

Como o projeto é construído estaticamente (Client-side), não há necessidade de builds complexos.

1. Clone o repositório:
   ```bash
   git clone https://github.com/GaBr1elZ/portifolio.git
   ```
2. Abra a pasta do projeto.
3. Utilize a extensão **Live Server** no VS Code ou apenas abra o arquivo `index.html` diretamente em seu navegador preferido.
